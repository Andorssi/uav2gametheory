## 0. はじめに
リポジトリ構成を示します．

- src : メインプログラム
- hex_LoS : LoS確率の導出のためのプログラムと結果
- subProg : UE生成等のサブプログラム

## 1. プログラム
gitを使っているのにも関わらずプログラムの進展があったときに別ファイルとして保存しています．基本的には数字が大きいものが最新版ということになります(uav2game○○)．

## 2. メインプログラム仕様書
メインプログラムがいつか完成したときに作成します．それまでは随時変更されていくのでご了承ねがいます．

## 3. 実行方法
基本的にはpythonのみで記述しているので，python環境があれば利用可能です．


メインプログラムの実行はコマンドライン上でのパラメータ指定は不要です．ただし，ue_positions_200.txt(ue_positions_400.txt)というUEの配置が書かれたテキストファイルはメインプログラムと同一ディレクトリに存在する必要があります．
```bash
python3 uav2game01.py
```
